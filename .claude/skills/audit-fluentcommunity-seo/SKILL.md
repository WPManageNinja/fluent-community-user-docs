# Audit FluentCommunity Docs — SEO

The SEO counterpart to `audit-fluentcommunity-docs`. That skill asks *"does the site build and are its
links alive?"*; this one asks *"can search engines and social platforms actually read it?"*

**Every check below runs against `.vitepress/dist/` — the built output, not the markdown.** That is the
whole point: the markdown can look perfect while the shipped HTML is missing the images, the meta tags,
or both. Run `npm run docs:build` first.

**Do not edit files.** Report findings and hand fixes to `edit-fluentcommunity-doc`.

---

## Agent Behavior Rules

1. **DO** run every check and report all results — don't stop at the first failure.
2. **DO** report counts plus the specific offending files.
3. **DO** treat Check 1 (SSR images) and Check 2 (meta tags) as ❌ must-fix; they are site-wide.
4. **DO NOT** modify any file — this skill is read-only.
5. **DO NOT** hand-roll a regex for markdown link destinations. Slugs in this repo contain `(`, `)`, and
   `&` (e.g. `add-custom-links-(pro)`), and a naive `\](/[^)]+\)` truncates them at the first `)` and
   reports ~20 phantom dead links. Parse the **built HTML** instead (Check 7).
6. **DO NOT** report `changelog` as an orphan — it is intentionally unlinked.
7. **DO NOT** propose appending `Related Articles` link blocks to pages — that pattern was tried and
   rejected as filler. See Check 7.

## 1. ❌ Images must server-render (highest value)

Markdown images pass through `.vitepress/theme/plugin-zoomable.ts` into `<ZoomableImage>`. If that
component is ever wrapped in `<ClientOnly>` again, **every image vanishes from the static HTML** — the
count silently drops to 0 and all alt text becomes invisible to crawlers. This regressed once already.

```bash
python3 - <<'PY'
import os,re,glob
src=html=0; bad=[]
for f in glob.glob('.vitepress/dist/*.html'):
    n=os.path.basename(f)[:-5]
    if n in ('404','index'): continue
    m=[i for i in re.findall(r'<img[^>]*>',open(f,encoding='utf-8',errors='replace').read())
       if 'VPImage' not in i]
    p=glob.glob('docs/*/'+n+'.md')
    if not p: continue
    s=len(re.findall(r'!\[[^\]]*\]\(',open(p[0],encoding='utf-8',errors='replace').read()))
    src+=s; html+=len(m)
    if s!=len(m): bad.append((n,s,len(m)))
print(f"markdown images: {src}   built <img>: {html}   mismatched pages: {len(bad)}")
for b in bad[:10]: print("  ",b)
PY
```

✅ expected: both counts equal (~426) and 0 mismatched pages. **A built count of 0 is a ❌ emergency.**

Also confirm alt text survived — expect `0`:
```bash
grep -o '<img[^>]*>' .vitepress/dist/*.html | grep -v VPImage | grep -cv 'alt="[^"]\+"'
```

## 2. ❌ Per-page canonical + Open Graph + Twitter tags

Generated by `head[]` and `transformPageData()` in `.vitepress/config.mts`.

```bash
python3 - <<'PY'
import glob,os,re,html as H
need=['og:title','og:description','og:url','og:image','og:site_name',
      'twitter:card','twitter:title','twitter:description']
files=[f for f in glob.glob('.vitepress/dist/*.html') if os.path.basename(f)!='404.html']
miss={k:[] for k in need}; nocanon=[]; bad=[]; mism=[]
for f in files:
    h=open(f,encoding='utf-8',errors='replace').read(); n=os.path.basename(f)[:-5]
    for k in need:
        if k not in h: miss[k].append(n)
    m=re.search(r'<link rel="canonical" href="([^"]+)"',h)
    if not m: nocanon.append(n); continue
    href=H.unescape(m.group(1))
    exp='https://docs.fluentcommunity.co/'+('' if n=='index' else n)
    if href!=exp: bad.append((n,href,exp))
    o=re.search(r'<meta property="og:url" content="([^"]+)"',h)
    if o and H.unescape(o.group(1))!=href: mism.append(n)
print(f"pages: {len(files)}")
print("missing tags:", {k:len(v) for k,v in miss.items() if v} or "none")
print(f"no canonical: {len(nocanon)}   wrong canonical: {len(bad)}   og:url != canonical: {len(mism)}")
for b in bad[:8]: print("  ",b)
PY
```

✅ expected: no missing tags, 0 wrong canonicals, 0 mismatches.

> **Note:** canonical hrefs legitimately contain `&amp;` — that is correct HTML attribute escaping,
> not a bug. Always `html.unescape()` before comparing.

Social card asset:
```bash
ls -l .vitepress/dist/og-image.png    # must exist; referenced as an absolute URL
```

## 3. ⚠️ Meta description health

```bash
python3 - <<'PY'
import re,glob,collections
lens=[];dup=collections.Counter();over=[];short=[];weak=[];nodesc=[]
for f in glob.glob('docs/**/*.md',recursive=True):
    t=open(f,encoding='utf-8').read()
    m=re.match(r'^---\n(.*?)\n---\n',t,re.S)
    if not m: continue
    d=re.search(r'^description:\s*(.+?)\s*$',m.group(1),re.M)
    if not d: nodesc.append(f); continue
    v=d.group(1).strip(); lens.append(len(v)); dup[v]+=1
    if len(v)>160: over.append((len(v),f))
    if len(v)<70: short.append((len(v),f))
    if v.lower().startswith(('learn how','an overview of')): weak.append(f)
lens.sort()
print(f"with description: {len(lens)}   missing: {len(nodesc)}")
print(f"min/median/max: {lens[0]}/{lens[len(lens)//2]}/{lens[-1]}")
print(f"over 160: {len(over)}   under 70: {len(short)}   formulaic opener: {len(weak)}")
print(f"duplicates: {sum(1 for k,c in dup.items() if c>1)}")
for n,f in sorted(over,reverse=True)[:10]: print("  ",n,f)
PY
```

✅ expected: 0 over 160, 0 under 70, 0 duplicates, 0 formulaic openers.

`docs/index.md` is skipped by this scan (its closing `---` has no trailing newline). Check the homepage
directly — it is the highest-value page:
```bash
grep -o '<meta name="description"[^>]*>' .vitepress/dist/index.html
```

## 4. ⚠️ Title / H1 alignment and title length

House style: frontmatter `title` and the body `# H1` are identical.

```bash
python3 - <<'PY'
import re,glob
mis=[];long_=[];dup={}
for f in glob.glob('docs/**/*.md',recursive=True):
    t=open(f,encoding='utf-8').read()
    m=re.match(r'^---\n(.*?)\n---\n(.*)$',t,re.S)
    if not m: continue
    ti=re.search(r'^title:\s*(.+?)\s*$',m.group(1),re.M)
    h1=re.search(r'^#\s+(.+?)\s*$',m.group(2),re.M)
    if not ti: continue
    a=ti.group(1).strip().strip('"\'')
    dup.setdefault(a,[]).append(f)
    if len(a)>60: long_.append((len(a),f))
    if h1 and h1.group(1).strip()!=a: mis.append((f,a,h1.group(1).strip()))
print(f"title != H1: {len(mis)}   over 60 chars: {len(long_)}   duplicate titles: {sum(1 for k,v in dup.items() if len(v)>1)}")
for f,a,b in mis: print(f"  {f}\n     title={a!r}  H1={b!r}")
PY
```

Also check brand/acronym casing (should return nothing):

## 6. ⚠️ Sitemap and robots

```bash
echo "loc:     $(grep -o '<loc>' .vitepress/dist/sitemap.xml | wc -l)"
echo "lastmod: $(grep -o '<lastmod>' .vitepress/dist/sitemap.xml | wc -l)"

cat docs/public/robots.txt
```

✅ `loc` should equal the page count. `lastmod` comes from git, so a page with **no commit history for
its path** legitimately has none — that resolves itself on the next commit, it is not a bug.

Known accepted ⚠️: sitemap URLs contain literal `(`, `)`, and `&` from the filename convention. These
are valid per RFC 3986. Renaming files to fix it would break every existing URL — **flag, don't fix.**

## 7. ⚠️ Internal link graph

**Critical:** every internal link in this repo is root-absolute (`/slug`), and VitePress **does not**
validate those at build time. A dead root-absolute link ships silently. This check is the only thing
catching them.

```bash
python3 - <<'PY'
import re,glob,os,html as H,collections
d='.vitepress/dist'
pages={'/'}; names=[]
for f in glob.glob(d+'/*.html'):
    n=os.path.basename(f)[:-5]
    if n=='404': continue
    names.append(n); pages.add('/' if n=='index' else '/'+n)
out=collections.Counter(); inb=collections.Counter(); dead=[]; total=0
for f in glob.glob(d+'/*.html'):
    n=os.path.basename(f)[:-5]
    if n=='404': continue
    h=open(f,encoding='utf-8',errors='replace').read()
    m=re.search(r'<main[^>]*>(.*?)</main>',h,re.S)      # body only, excludes sidebar
    for mm in re.finditer(r'href="(/[^"#?]*)',m.group(1) if m else ''):
        href=H.unescape(mm.group(1))
        if href.startswith('/images/'): continue
        total+=1
        p=href.rstrip('/') or '/'
        if p not in pages: dead.append((n,href))
        t=p.lstrip('/') or 'index'
        if t!=n: out[n]+=1; inb[t]+=1
print(f"in-body internal links: {total}   avg/page: {total/len(names):.1f}")
print(f"DEAD links: {len(dead)}")
for x in dead[:15]: print("  ",x)
print("dead ends (0 outbound):", sorted(n for n in names if out[n]==0 and n!='index'))
print("no inbound:",            sorted(n for n in names if inb[n]==0 and n!='index'))
PY
```

✅ expected: **0 dead links** — that part is a ❌ if it ever fails.

The dead-end / no-inbound lists are informational ⚠️ only. Report the counts (currently ~28 each) and
stop there.

> **Do not "fix" these by appending boilerplate `Related Articles` link blocks to pages.** That was
> tried and explicitly rejected — it reads as filler. If internal linking is to be improved, the links
> must be **contextual**: worked into existing prose where the reference is genuinely useful, using the
> target's real title as anchor text (never "click here"). Treat that as an editorial task requiring
> author sign-off, not something this audit applies.

## Quick Reference

- Everything is checked against **`.vitepress/dist/`**, never the markdown alone.
- The one regression that matters most: `<ClientOnly>` around `<ZoomableImage>` → 0 images in static HTML.
- Root-absolute links are **not** build-verified — Check 7 is the only safety net.
- Slugs contain `(`, `)`, `&`: parse built HTML, `html.unescape()` before comparing, never regex the markdown.
- `changelog` is intentionally orphaned; sitemap parens and git-less `lastmod` are accepted ⚠️.
